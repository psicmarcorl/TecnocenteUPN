# Tecnocente · UPN 112

Espacio docente de Marco Antonio Rojas López (Universidad Pedagógica Nacional, Unidad 112 Celaya): herramientas para el aula, materiales por materia, horario y pausas de bienestar.

Sitio publicado con GitHub Pages a partir de la rama `main`.

## Estructura
- `index.html` — página principal (diseño responsivo, tema claro y oscuro).
- `herramientas/` — aquí irán las herramientas de clase (equipos, ruleta, trivias, juegos).
